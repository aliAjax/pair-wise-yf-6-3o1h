# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

备件领退：
- 备件登记名称、单位、库存、单价、安全库存；库存达到或低于安全库存即预警。
- 事项进入「处理中」后才能领用；库存不足时整笔拒绝、不扣库存，页面提示还缺多少。
- 可按原领用记录退回未用完零件，退回不超过该次净领用；库存与事项材料成本随净用量恢复。
- 同一零件多次领用合并展示，每次领用、退回明细可展开查看。
- 删除事项时未退净用量按报废处理，库存不恢复；旧台账数据自动迁移照常打开。
