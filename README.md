# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

第二版：备件领退纳入维修事项。

- 备件台账：每种零件登记库存、单价、安全库存，可编辑、删除（已有领用记录的零件不可删）；库存低于安全库存时在头部统计和台账中同步预警。
- 领用：事项开工（处理中/已完成）后才能领用；库存不足时不扣任何库存，页面提示还缺多少。
- 退回：未用完的零件从原领用记录退回，退回数量不能超过该次净领用；库存和事项材料成本随净用量恢复。
- 展示：同一零件重复领用合并展示净用量，同时保留每次领用和退回记录。
- 清理：删除事项时未退回的零件按报废处理（库存不恢复，台账累计报废数）。
- 兼容：旧数据照常打开，自动补齐台账与领用字段。
